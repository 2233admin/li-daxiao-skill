# li-daxiao：模拟李大霄的 Claude Code skill 做好人卖好股

和"李大霄"聊 A 股。人设依据他的著作《李大霄投资战略》蒸馏而成，包括世界观、24 条判断大势的规则、说话方式、2007–2024 年的立场时间线和 54 个历史案例。它能读取当天和盘中的 A 股数据，用他的口吻聊盘前、盘中、盘后和周报，做突发点评和持仓体检，按他的尺子筛"好股票"，回答读者来信。

> **这是模拟，不是李大霄本人**，与他本人及其所在机构无关。内容是对公开著作的概括和整理，只引用很短的标志性用语，不收录原文。
> **不构成投资建议。** skill 不给个股买卖点、仓位和杠杆建议；筛出来的名单是机械筛选结果，不代表应该买。

## 能做什么

| 你说 | 它做什么 |
|---|---|
| 李老师，明天盘前怎么看 | 拉估值、两融、外盘等数据，判断处在"勇气 / 坚持 / 淡泊"哪个阶段，找最像的历史时刻 |
| 现在盘中怎么样 | 新浪批量行情，看好股票池今天打了几折 |
| 今天盘后怎么看 / 这周怎么看 | 盘后复盘、周报 |
| 暴跌了 / 降息了 | 突发点评，对照历史同类事件 |
| 好股票是哪些 | 按他的尺子筛：行业相对估值、连续分红、股息率高于国债等 |
| 我拿着 X、Y 帮我看看 | 持仓体检，只对照标准，不替你下结论 |
| 出戏 / 他准不准 | 切回分析师视角，用观点账本的统计说他哪类判断靠得住 |

## 他准不准（观点账本）

从书里抽出 253 条带日期的判断，去重后得到 76 个 A 股事件，按之后的上证走势打分。基准：2007-11 到 2024-10 任意一天之后 60 日上涨的概率是 47.2%。

- **看空时信息量高**：2007–2023 年共 9 次，之后 60 日平均 -16.1%，方向命中 89%。
- **看多时信息量低**：2007–2023 年 60 日上涨概率 67%；2024 年天天看多，上涨概率 43%，和基准持平。
- 他给的底部点位，±3% 容差下守住率 54%：底是估值区间，不是支撑位。
- 书是他本人选编的，统计结论偏乐观。

完整统计见 `references/score_summary.json`。回放盲测（隐去日期，让模型按人设判断方向）见 `tests/replay/`，v2 方向一致率 84%。

## 安装

```bash
git clone https://github.com/2233admin/li-daxiao-skill ~/.claude/skills/li-daxiao
pip install -r ~/.claude/skills/li-daxiao/requirements.txt
```

Windows 上把 `~/.claude/skills` 换成 `%USERPROFILE%\.claude\skills`。需要 Python 3.10+。

### 第一次用：先拉数据

仓库不带数据缓存，第一次要先拉（几分钟，取决于网络）：

```bash
cd ~/.claude/skills/li-daxiao/scripts
python daily_card.py --fetch     # 估值、国债、破净率、两融、新股、外盘等
python fetch_screen.py           # 选股要用的个股数据（较慢）
```

缓存写在 `scripts/data/`。之后 skill 会按需刷新；联网失败时用缓存，并注明数据截至哪天。

数据来自 [akshare](https://github.com/akfamily/akshare)（东方财富、乐咕、新浪、中证指数等公开接口）和新浪实时行情。接口可能变动或限流，某一项拉不到时那一块会跳过，不影响其它。akshare 改过函数名的由 scripts/akcompat.py 兼容，新旧版本都能跑。东方财富限流时（报 Push2RateLimitError）等几分钟再拉，别连着重试。

## 用法

装好以后，在 Claude Code 里直接说"李老师，……"或者 `/li-daxiao`。

## 目录

```
SKILL.md                 入口：场景路由、判断规则、守住角色、出戏模式
references/
  voice.md               说话方式、用语、禁区
  formats.md             各场景模板与字数
  worldview.md           信条、R1–R24 规则、盘前/盘中/盘后 checklist
  cases.md               54 个历史案例（998、6124、1664、钻石底、地球顶、924……）
  events.md              突发事件类型与案例对照
  positions.md           2007-11 到 2024-10 立场时间线（由账本生成）
  data.md                脚本输出、选股细则、数据维护
  widget.md              盘前/盘后可视化卡片模板（环境有内联可视化工具时用）
  score_summary.json     观点账本统计
scripts/                 取数与计算脚本
tests/replay/            回放盲测
```

# 数据、脚本与维护

SKILL.md 只放路由和判断规则。这里放各脚本输出怎么读、选股尺子的细则，以及数据维护。

## 1. 日卡 `daily_card.py`

运行 `python scripts/daily_card.py [--fetch]`。`--fetch` 会先拉 6 个历史文件，再调用 `fetch_extra.py`；缓存已经是最近一个交易日的，可以不加。

| 行 | 内容 | 读法 |

| `[F1蓝筹]` | 上证50 滚动 PE，2005 年起的分位 | **定阶段用这一行** |
| `[R8补]` | 破净股占比 | 越多越便宜 |
| `[F8]` | 距 3 年高点的回撤 | |

| `[F6]` | 融资余额分位、20 日变化、融资买入、维持担保比例 | 标明维持担保比例截至哪天 |

## 2. 历史相似 `analog.py`

- 输出状态向量、最像的书中案例、最像的历史月末，各附之后 60 日和 250 日的走势。
- 按距离判断：小于 0.1 算很像，0.1–0.2 算有几分像，大于 0.2 就是没有很像的，直说。
- `--top 60` 可以查离某个历史状态多远。`--asof` 用于回测某一天，`--exclude-after` 用于回放盲测。
- 全A分位的窗口和 daily_card 不同，不要混用；上证50 分位两边口径一致。

## 3. 选股尺子 `fetch_screen.py` → `screen.py`

1. `fetch_screen.py`：拉 5 年年报和 2 期中报的分红送配、全A行情、新浪行业成分、中证指数成分。历年年报已缓存的不重拉，全部取完约 3–5 分钟。
2. `screen.py --csv`：结果落到 `data/screen/result_<日期>.csv`，含精选标记和 dps_ttm，盘中卡会用到。阈值全部写在脚本顶部的 `RULE` 里。

**规则**（依次过，漏斗会打印每一关剩多少只）：
- 高估五类，一票否决：
  - 小：市值 < 100 亿；
  - 新：上市不满 3 年；
  - 差：ST、近 5 年有亏损、或净利同比 < -20%；
  - 题材和伪成长：由估值关挡掉。
- 估值低：
  - 非金融：PE ≤ 20，且不高于行业中位数（新浪行业），PB ≤ 3。
  - 金融：PE ≤ 15，PB ≤ 2。金融不和行业中位数比，否则招行、工行这类有溢价的龙头会被刷掉。
- 分红真：5 年连续现金分红；股息率 ≥ 10Y + 1.5pp；派息率 ≥ 20%。股息率按近 12 个月算：最近年报加最近中报，今年中报还没出的退回用去年中报。
- 规模档：龙头级 ≥ 1000 亿，大 ≥ 300 亿，中 ≥ 100 亿。

**输出**：
- 非金融按行业分组，每个行业取行业内市值前 3，"行业地位"显示为"第 N / 共 M 家"。
- 金融单独一段。
- 末尾是**精选档**：
  - 行业前 3（金融放宽到前 10）、市值 ≥ 300 亿、EPS 波动 ≤ 0.2、没有任何标记、股息率 ≥ 3.5%、净利同比 ≥ 0。
  - 行业第一、且 EPS 波动 ≤ 0.15 的，净利同比放宽到 ≥ -10%，表里标"龙头放宽"。

**标记**：
- `周期?`：近 5 年 EPS 变异系数 > 0.35，PE 低可能是利润正在高点。
- `特别分红?`：近 12 个月分红超过了 EPS，股息率不可持续。
- PB 显示为空：源数据的每股净资产有错（例如中国移动），这一关不拿它卡。

**`--explain 代码,…`**：逐只列出读数和卡在哪一关。

**量不了的**："全国第一"只用行业内市值排名代替；新浪的行业归类偶有错（华东医药被归到零售业）；个股 PE 用年报 EPS，行业中位数用的是新浪动态 PE，两边口径不完全一致。

## 4. 持仓体检 `checkup.py`

- 用法：`checkup.py 代码或名称 … [--cost 代码=成本,…]`。任何 A 股都能量。没有行情的（北交所夜间、刚上市的）显示"无行情"，其余项照量。
- 逐只输出好股票四条（行业地位、估值、分红、盈利）和高估五类，再贴一个体检标签。
- 分红送配表只收录有预案的公司，不分红的年份没有 EPS，显示为"-"。盈利一关按已知年份判，至少要有 3 年数据。

## 5. 盘中 `intraday.py`、周报 `weekly.py`

- `intraday.py [--pool core]`：大约 6 秒。指数和个股走新浪 hq 批量接口，涨跌家数走乐咕实时。好股票池读最近一次的 `result_*.csv`，盘中不重新过尺子。
- `weekly.py [--days 5|20]`：区间内指数涨跌和大小盘分化、估值分位、破净、股债差、两融、ETF 份额、新发基金的变化。全A PE/PB 源是月末序列，所以区间起点取最近的月末。
- 信号灯和好股票池不存逐日历史。

## 6. 数据源与维护

- 所有脚本都依赖 akshare 和 pandas，缓存放在 `scripts/data/`。
- `fetch_extra.py` 的每个源都在独立子进程里跑，带硬超时：akshare 本身不设请求超时，2026-11-25 曾经一个源挂住 3 小时。
  - `--only a,b` 只跑指定的源，`--skip repurchase` 跳过慢的源。
  - ETF 份额首次回补用 `--etf-backfill 60`，放后台跑。
- 数据源只用 akshare（东方财富、乐咕、新浪、中证指数、上交所等公开接口），盘中行情走新浪批量接口。akshare 改过函数名的，由 `scripts/akcompat.py` 统一映射。
- 东方财富接口短时间请求太多会限流（约 5 分钟恢复，反复触发更久）。限流时别重试，先用缓存。
- 案例索引在 `references/cases_index.csv`（id、anchor、name）。新增案例后，要重新生成 `cases.md` 里的锚定日数据。
- 观点账本的逐条原始数据和打分脚本不随本 skill 发布，这里只带结果：`score_summary.json` 和由账本生成的 `positions.md`。
- 回放盲测放在 `tests/replay/`，用 `build.py` 打包、`score_replay.py` 打分。
